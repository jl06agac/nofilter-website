# ── 29 Aug · THE AI CRAWLERS, NAMED ON PURPOSE ──────────────────────────────
# The wildcard above already allows all of these, so none of the lines below
# change what any crawler is permitted to do today. They are here so the
# decision is on the record and cannot be reversed by accident — the common way
# a site disappears from AI answers is somebody adding a blanket Disallow for
# "the scrapers" without knowing that three of them do three different jobs.
#
# OpenAI runs three, and they are not interchangeable:
#   GPTBot          collects content that trains future models
#   OAI-SearchBot   builds the index behind ChatGPT's search results
#   ChatGPT-User    fetches a page live, when someone's question needs it
# Block GPTBot to stop "scraping" and you keep the search index but lose the
# model's background knowledge of who NoFilter is. Block OAI-SearchBot and you
# vanish from the answers entirely. We want all three.
#
# The others are the same shape for the other assistants.
