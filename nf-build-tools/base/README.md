# base/

## `NoFilter-Website-Master-2026-08-31.html`

**This is not the current site.** It is the master as it stood on **31 August 2026**,
and it is the starting point the patch chain is applied to. Renamed from `PRISTINE.html`
on 4 Sep 2026, because "pristine" said nothing about what the file is or when it is from.

The current site is `../../NoFilter-Website-Master.html` — the one with **no date** in its
name. Dated file = an old snapshot. Undated file = live.

Proven to be the 31 Aug state: md5 `371ba7a285`, byte-identical to the
`NoFilter-Website-Master.PRE-DOSSIER.html` backup of that date.

**Do not edit this file, and do not add so much as a comment to it.** It is copied
verbatim as step one of `../build.sh`, so any byte added here lands in the rebuilt master
and the chain stops reproducing. That is not hypothetical: a banner was added to it on
4 Sep and the rebuild came out 653 bytes heavy until it was taken back out. This README
exists so the explanation can live next to the file instead of inside it.

To change the site: write a patch in `../patches/`, add it to the chain in `../build.sh`,
re-run. Never edit the master or this base by hand.
