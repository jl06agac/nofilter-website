“See full details” — four affordances

Real card CSS and real machine art. Measured: the current text link costs 26px of a 701px card (3.7%), so this is a tidiness decision rather than a space one. What actually differs between these is how obvious it is that spec detail exists at all.

A

What is live now

A monospace text link on its own row. Legible and unmissable, but it is a thin 18px target and it interrupts the card’s vertical rhythm.

B

Labelled chip inside the photo

Costs zero vertical space, keeps the word “Details”, and turns an 18px text line into a proper 30px pill. Mirrors the tick that already sits top-right on a picked card, so the corner already means “status lives here”.

C

Whole photo clickable, hover reveals

Cleanest at rest — one small circular mark, and the whole image explains itself on hover. The risk is touch: there is no hover on a tablet, so the mark is doing all the work.

D

Vertical bar alongside the image

Your idea, with the label kept and rotated so it is not mystery meat. Distinctive, and it costs no vertical space — but it narrows the photo by 30px, rotated type is slower to read, and on a phone this column has nowhere to go.

E

B at rest, D on hover

The chip holds the label while nothing is happening, so the control is never unlabelled — then your bar slides in over the photo on hover. Because the bar is not in the layout at rest it costs the image no width, which was D’s one real penalty. Both targets open the same panel. Hover a card.

G

No resting chip · bar on hover · label treatments

Your version: nothing at rest, the bar arrives when the cursor reaches the card. The four differ only in the label. Card 4 shows the touch fallback — on a device with no hover the chip stays put, so a tablet user still has a target. In the real build that is one @media (hover: none) rule, not a separate design. Hover each card.

F

E on the complete card — live

The whole thing working: hover the photo for the bar, switch Rental / Purchase, change the term, open Extras and tick the options.
